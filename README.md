Name

Symptoms
Diagnosis
Medical treatment
Prescribed medicine

Date and time

Medicine Inventory Integration

When medicine is prescribed or treatment is given:

The system should automatically:
Deduct medicine quantity from inventory
Update remaining stock
Prevent dispensing if stock is insufficient

Features
Manual medicine input per clinic PC

Quantity
